## 🚀 Setting up the application

After you install the program, you must set it up for your first use. Launch the Salsyx icon from your desktop or your Start menu.

The setup screen asks for a storage location. This folder holds the archives of the GitHub repositories you collect. Choose a folder on your computer with enough space for large amounts of data. Click the Browse button to select a folder, then click Save.

The application checks for a connection to your local database during this step. It uses a storage system called Postgres to keep your information organized. The software handles this setup automatically. You do not need to perform manual configuration for this database.

## 🔍 How to search and preserve

The main interface features a search bar. Type the name or the URL of a public GitHub repository into this field.

1. Click the Search button.
2. Review the results to confirm the correct repository.
3. Click the Preserve button next to the project name.
4. The status bar shows the progress of the download.
5. Wait for the green checkmark to confirm the archival process.

You can queue multiple repositories at once. The software processes them in order. You can view your saved projects by clicking the Library tab at the top of the window. 

## ⚙️ Managing your archives

The Library tab acts as your personal catalog. It lists every repository you saved. Each entry includes the project name, the date you saved it, and the current size on your disk.

If a project updates, you can click the Refresh button. This fetches the latest changes from the original source. If you no longer need a project, select the entry and click Delete. This removes the data from your computer and frees up disk space.

## 🛡️ Privacy and data security

Salsyx runs locally on your machine. The software does not send your personal search history to external servers. Your saved archives live only on your hard drive. This ensures you maintain full control over the data you collect. The application connects to GitHub only to retrieve public repository details.

## ❓ Troubleshooting common issues

If the software fails to start, check your internet connection. Salsyx requires a network connection to verify the installation files during the initial launch.

If the download progress stays at zero, verify your storage space. The software needs room to write the archived files. Clear old files if your hard drive is near capacity.

If the application runs slowly, close other demanding programs like video games or high-resolution editors. Salsyx uses system resources to process code archives. Give it a few minutes to complete complex tasks before trying to interact with the interface again.
